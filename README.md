# expense-tracker-python
Python Expense Tracker using CSV and Matplotlib

This is a simple command-line Expense Tracker built using Python.
It helps users record daily expenses, organize them by category, and visualize spending patterns using a pie chart.

✨ Features
Add expenses with amount, category, and date
View all stored expenses
Calculate total expenditure
Search expenses by category
Visualize expense distribution using a pie chart 📊
Stores all data in a CSV file
🛠️ Tech Stack
Python 🐍
CSV File Handling
Matplotlib (Data Visualization)

The project uses a pie chart to show how expenses are distributed across different categories, making it easier to understand spending habits visually.

I also added a demo pie chart.
